# Credit_Risk_Analysis
The aim of the project was to prepare a complete dataset for credit risk analysis and for building a model to predict bank customer default.

The project was developed in SAS. The source data came from several related tables containing information about customers, bank accounts, transactions, payment cards, loans, standing orders, and customers’ places of residence.

As part of the project, the data was cleaned, transformed, and combined into a single analytical dataset. Each record in the final dataset represents a bank account and the loan assigned to it.
